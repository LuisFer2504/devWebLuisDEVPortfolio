- Responsive design
- Clean Architecture
- Reusable Components
- Framer Motion Animations
- SEO Optimized
- TypeScript
- Tailwind CSS
- Modern UI/UX

- Next.js
- React
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide React
